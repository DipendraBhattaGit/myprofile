# Dipendra Bhatta portfolio
Server: `cd server && cp .env.example .env` (fill SMTP_* and CONTACT_EMAIL; MONGODB_URI optional) `&& npm i && npm run dev`
Client: `cd client && npm i && npm run dev`
Photo: save as `client/src/assets/profile.jpg`. Links/number: `client/src/data/socials.js`.
Postman: POST http://localhost:5000/api/contact with {name,email,subject,message}.
